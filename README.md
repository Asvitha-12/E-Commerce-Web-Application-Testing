# E-Commerce Web Application Testing

## Overview

This project demonstrates end-to-end Manual Testing of an E-Commerce Web Application. The project covers complete Software Testing Life Cycle (STLC) activities including test planning, test scenario creation, test case design, execution, defect reporting, API testing, SQL validation, and test reporting.

---

## Project Modules

- User Registration
- User Login
- Logout
- Product Search
- Product Details
- Shopping Cart
- Checkout
- Payment
- Order Confirmation
- Contact Us

---

## Testing Performed

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Value Testing
- Smoke Testing
- Regression Testing
- API Testing using Postman
- SQL Database Validation
